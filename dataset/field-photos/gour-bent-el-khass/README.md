# Gour Bent El Khass photo upload

Upload the original JPG/JPEG/PNG/WEBP files directly into this folder.

- Keep every original filename; do not rename the photos.
- Do not upload screenshots of the GitHub interface.
- On the next Android build, the workflow automatically copies the photos byte-for-byte into the app's offline gallery.
- The same files are added to the recognition dataset as `pending` references. They are not silently approved as model-training truth and cannot activate recognition by themselves.
- The images are associated with `gour-bent-el-khass`, based on the user's identification of this batch.

Supported file types: JPG, JPEG, PNG, WEBP.
