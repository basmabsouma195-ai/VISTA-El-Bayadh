# Photo research inventory

This folder tracks candidate public photographs researched for VISTA El Bayadh. It is deliberately separate from the app's runtime image catalogue.

## Current status
- Candidate source pages have been identified for Boussemghoun, Brezina, El Bayadh city, Arbaouat and nearby sites.
- No candidate in this inventory is automatically approved for app distribution or visual recognition.
- Every individual Wikimedia Commons file page must be checked for its actual license, author, attribution wording, and any share-alike requirements before copying the binary into the repository.
- A location match must be confirmed from the image description and visual content. A village panorama is not automatically a photograph of its ksar, cave, rock-art panel, or other specific attraction.

## Workflow
1. Open the individual source file page.
2. Record the original file URL, author, license name, license URL, required attribution, and source page.
3. Inspect image quality and confirm the depicted landmark.
4. Download an appropriately sized original and preserve attribution metadata.
5. Add it to the app's local assets only after review.
6. Keep recognition-reference approval separate; web photographs are not automatically valid field references.

See [photo_candidates.json](./photo_candidates.json) for the research register.
